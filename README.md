## 📖 About This Repository
Welcome to my **Design and Analysis of Algorithms (DAA)** workspace! This repository contains my academic coursework, practical lab implementations, and algorithmic problem-solving codes. The core focus here is writing highly optimized code to understand time complexities, space complexities, and algorithmic paradigms.

The majority of the algorithms are implemented natively in **C**. For visualizing algorithmic growth and rendering graphs, I have leveraged **SDL (Simple DirectMedia Layer)** directly in C for most of the labs, utilizing **Python (Matplotlib)** exclusively for the introductory visualizations in Lab 1.
